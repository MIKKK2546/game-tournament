# เอกสารความต้องการของระบบ (Requirements)

## 1. วัตถุประสงค์

พัฒนาเว็บไซต์สำหรับจัดการแข่งขันเกม เพื่อให้ผู้จัดบันทึกข้อมูลทีมและสมาชิก สุ่มทีมอย่างเป็นธรรม และติดตามผลการแข่งขันแบบแพ้คัดออกได้ในที่เดียว

## 2. ผู้ใช้งาน

| ผู้ใช้ | คำอธิบาย |
|---|---|
| ผู้จัดการแข่งขัน | เพิ่ม แก้ไข ลบข้อมูล สุ่มทีม และบันทึกผลการแข่ง |

ระบบยังไม่มีการล็อกอิน ผู้ใช้ทุกคนมีสิทธิ์เท่ากันบนเครื่องของตัวเอง

## 3. ความต้องการเชิงหน้าที่ (Functional Requirements)

| รหัส | ความต้องการ |
|---|---|
| FR-01 | เพิ่มเกมพร้อมรูปเกมได้ และลบเกมได้ (ลบไม่ได้ถ้ายังมีทีมที่เล่นเกมนั้นอยู่) |
| FR-02 | เพิ่มทีมโดยระบุชื่อทีม เกมที่เล่น และรูปทีม |
| FR-03 | แก้ไขชื่อทีม เกมที่เล่น และรูปทีมได้ (เปลี่ยนรูปหรือลบรูปได้) |
| FR-04 | ลบทีมพร้อมสมาชิกทั้งหมดได้ โดยมีหน้าต่างให้ยืนยันก่อน |
| FR-05 | เพิ่ม แก้ไข และลบสมาชิกในทีม โดยระบุชื่อ ตำแหน่ง และรูป |
| FR-06 | แสดงรายการทีมทั้งหมด และกรองตามเกมได้ |
| FR-07 | หน้าภาพรวมแสดงจำนวนเกม ทีม และสมาชิกทั้งหมด |
| FR-08 | วงล้อสุ่มทีม: เพิ่มชื่อได้โดยพิมพ์เอง หรือกดชื่อทีมที่มีเพื่อเติมลงกล่องข้อความแล้วแก้ไขต่อได้ก่อนกดเพิ่ม มีปุ่มเลือกทุกทีม ลบชื่อรายตัว และล้างวงล้อ |
| FR-09 | หมุนวงล้อได้เมื่อมีอย่างน้อย 2 ชื่อ ทุกชื่อมีโอกาสถูกเลือกเท่ากัน มีเอฟเฟกต์หมุน ตัวชี้สะบัด เน้นผู้ชนะ และ confetti และมีตัวเลือกให้เอาชื่อที่ถูกสุ่มออกหลังหมุน |
| FR-10 | สายแข่ง: เลือกทีมที่เข้าร่วมอย่างน้อย 2 ทีม เลือกสุ่มลำดับได้ และสร้างสายแข่งแบบแพ้คัดออก (single elimination) รองรับจำนวนทีมที่ไม่ลงตัวด้วยการให้บาย (bye) |
| FR-11 | กดชื่อทีมที่ชนะในแต่ละคู่เพื่อให้เข้ารอบถัดไป กดซ้ำเพื่อยกเลิกผล และเมื่อแก้ผลรอบก่อนหน้า ผลของคู่ที่ขึ้นต่อกันจะถูกล้าง |
| FR-12 | แสดงชื่อแชมป์เมื่อรอบชิงชนะเลิศมีผู้ชนะ |
| FR-13 | ล้างสายแข่ง หรือสร้างสายใหม่ได้ โดยมีหน้าต่างให้ยืนยันก่อน |
| FR-14 | บันทึกข้อมูลอัตโนมัติในเบราว์เซอร์ และโหลดกลับมาเมื่อเปิดเว็บใหม่ |
| FR-15 | เมนูแท็บสำหรับสลับหน้า: ภาพรวม เกม ทีม วงล้อสุ่มทีม สายแข่ง |

## 4. ความต้องการที่ไม่ใช่เชิงหน้าที่ (Non-functional Requirements)

| รหัส | ความต้องการ |
|---|---|
| NFR-01 | ใช้งานได้ทั้งบนคอมพิวเตอร์และมือถือ (responsive) |
| NFR-02 | รองรับโหมดสว่างและโหมดมืดตามการตั้งค่าของเครื่อง |
| NFR-03 | รูปที่อัปโหลดถูกย่อให้ด้านยาวไม่เกิน 360 พิกเซลและบีบอัดเป็น JPEG เพื่อประหยัดพื้นที่จัดเก็บ |
| NFR-04 | ใช้งานได้โดยไม่ต้องติดตั้งโปรแกรมหรือเซิร์ฟเวอร์ (ไฟล์ HTML ไฟล์เดียว) |
| NFR-05 | ข้อความและเมนูเป็นภาษาไทย ฟอร์มมีป้ายกำกับชัดเจน |
| NFR-06 | ข้อความที่ผู้ใช้พิมพ์ถูกแปลงอักขระพิเศษก่อนแสดงผล เพื่อป้องกันการแทรกโค้ด |

## 5. ข้อจำกัดและข้อสมมติ

- ข้อมูลถูกเก็บใน localStorage ของแต่ละเบราว์เซอร์ พื้นที่จำกัดตามเบราว์เซอร์ (โดยทั่วไปราว 5 MB)
- ยังไม่มีเซิร์ฟเวอร์และฐานข้อมูลกลาง ข้อมูลไม่ถูกแชร์ระหว่างเครื่อง
- ฟอนต์ภาษาไทยโหลดจาก Google Fonts จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อให้แสดงฟอนต์ตามที่ออกแบบ
- สายแข่งรองรับแบบแพ้คัดออกแบบเดี่ยวเท่านั้น

## 6. เทคโนโลยี

HTML, CSS, JavaScript, Canvas API, localStorage, Google Fonts

## 7. แนวทางพัฒนาต่อ

- เพิ่มเซิร์ฟเวอร์และฐานข้อมูล (เช่น PHP + MySQL หรือ Node.js) ตามแบบใน [database.md](database.md) เพื่อให้หลายคนเห็นข้อมูลเดียวกัน
- เพิ่มระบบล็อกอินสำหรับผู้จัด และให้ผู้เข้าชมดูอย่างเดียว
- บันทึกสกอร์ของแต่ละคู่
- รองรับสายแข่งแบบอื่น เช่น แพ้สองครั้งตกรอบ หรือแบ่งกลุ่มแข่งพบกันหมด
