## 1. แนวคิดและที่มา

การจัดแข่งเกมในกลุ่มเพื่อนหรือชมรมมักใช้การจดชื่อทีมในกระดาษหรือแชต ทำให้ข้อมูลกระจัดกระจาย จับคู่ไม่เป็นธรรม และอัปเดตผลยาก โปรเจคนี้จึงรวมสิ่งที่ผู้จัดต้องใช้ไว้ในหน้าเว็บเดียว

- **เก็บข้อมูลเป็นระเบียบ:** เกมที่แข่ง ทีม สมาชิก และรูปภาพ
- **สุ่มอย่างยุติธรรม:** วงล้อสุ่มให้ทุกทีมมีโอกาสเท่ากัน
- **ติดตามผลง่าย:** สายแข่งแบบแพ้คัดออก กดชื่อทีมที่ชนะแล้วเข้ารอบถัดไปทันที

## 2. ฟีเจอร์หลัก

| หมวด | รายละเอียด |
|---|---|
| ภาพรวม | สรุปจำนวนเกม ทีม และสมาชิกทั้งหมด |
| เกม | เพิ่ม/ลบเกม พร้อมรูปเกม |
| ทีม | เพิ่ม/แก้ไข/ลบทีม เลือกเกมที่เล่น ใส่รูปทีม กรองทีมตามเกม |
| สมาชิก | เพิ่ม/แก้ไข/ลบสมาชิก ใส่ชื่อ ตำแหน่ง และรูป |
| วงล้อสุ่มทีม | พิมพ์ชื่อหรือกดเลือกจากทีมที่มี หมุนวงล้อพร้อมเอฟเฟกต์ |
| สายแข่ง | เลือกทีม สร้างสายแพ้คัดออก กดเลือกผู้ชนะเพื่อเข้ารอบ แสดงแชมป์ |

## 3. เทคโนโลยีที่ใช้

- HTML, CSS, JavaScript (ไม่ใช้เฟรมเวิร์ก)
- Canvas API สำหรับวาดวงล้อและเอฟเฟกต์
- localStorage สำหรับบันทึกข้อมูลในเบราว์เซอร์
- Google Fonts (Kanit, Sarabun)

## 4. วิธีใช้งาน

1. ไปแท็บ **เกม** แล้วเพิ่มเกมที่จะแข่ง
2. ไปแท็บ **ทีม** แล้วเพิ่มทีม กดที่ทีมเพื่อเพิ่มสมาชิก
3. ใช้แท็บ **วงล้อสุ่มทีม** หรือ **สายแข่ง** เมื่อพร้อมแข่ง

## 5. วิธีรันโปรเจค

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม หรือใช้ส่วนเสริม Live Server ใน VS Code ก็ได้

## 8. ข้อจำกัดของเวอร์ชันปัจจุบัน

ข้อมูลทั้งหมดถูกเก็บในเบราว์เซอร์ของแต่ละเครื่อง (localStorage) ยังไม่มีเซิร์ฟเวอร์และฐานข้อมูลกลาง ดังนั้นคนละเครื่องจะไม่เห็นข้อมูลของกันและกัน การออกแบบฐานข้อมูลใน `docs/` เป็นแบบสำหรับพัฒนาต่อเป็นระบบที่มีเซิร์ฟเวอร์
